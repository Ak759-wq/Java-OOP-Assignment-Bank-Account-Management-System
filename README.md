# Java-OOP-Assignment-Bank-Account-Management-System

A simple Java program that demonstrates Object-Oriented Programming (OOP) concepts using classes and objects.

### Features
- Create bank accounts using a parameterized constructor.
- Deposit money into accounts.
- Withdraw money with balance checking.
- Check current balance.
- Display account details.

### Concepts Used
- Classes and Objects
- Constructors
- Methods
- Instance Variables

### How to Run
1. Save the code as `Main.java`.
2. Compile: `javac Main.java`
3. Run: `java Main`

The program creates two independent bank accounts and performs deposit and withdrawal operations on both.
